OceanTrace Architecture

SIH 2026 · PS 26143 · NTRO

SAR oil-spill detection with AIS vessel attribution. Modules never call each other — every stage writes a frozen file contract, the next stage reads it, and the platform renders nothing that isn't in a contract file. Every external dependency carries a fallback chain that ends network-free.

LEGEND

Learned models — YOLO11 screen (DARTIS) · U-Net segment (Trujillo)
Physics — OpenDrift particle transport, hindcast & forecast
Evidence — gates and weighted attribution scoring
Contracts & platform — the file bus and everything that reads it
Fallback path — always labelled in the UI, never hidden

DESIGN RULES

  • Every fallback chain ends network-free — the demo survives airplane mode
  • Provenance is worn, not hidden: each layer badges REAL / CACHED / SYNTHETIC
  • Scores are evidence for investigators, never verdicts
  • One normalisation config is fingerprinted end-to-end; a mismatched model refuses to run
  • A failed stage marks itself and the run continues — the page never goes blank
